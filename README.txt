HOW IT WORKS
1. Host this folder on any static host such as GitHub Pages or Cloudflare Pages.
2. Once the site has a public HTTPS address, program that URL into your NFC card.
3. Use the same URL to create a QR code for the printed card as a backup.
4. If your details change later, edit the webpage/VCF while keeping the same URL.
   You do NOT need to reprogram the physical NFC card.
